Xưởng ảnh

Hồng Đức Tu Tiên Lộ · đã có 44/75 ảnh, còn thiếu 31. Công việc của bạn: copy prompt → vẽ → chọn ảnh ngay dưới prompt. Phần còn lại tự động.

⚡ Cách làm — 2 bước

  1. Copy prompt: bấm 📋 Copy — có 3 mức: prompt từng ảnh, prompt cả nhóm cảnh, hoặc prompt toàn bộ một phần. Dán vào AI tạo ảnh (Gemini…). Nhớ chọn đúng tỷ lệ ghi trên thẻ.
  2. Vẽ ảnh: nếu thẻ ghi đính kèm ảnh mẫu, tải ảnh mẫu ở mục 📚 Thư viện ảnh mẫu và đính kèm để giữ mặt nhân vật.
  3. Chọn ảnh ngay dưới prompt: vẽ xong, bấm vào ô 📷 ngay dưới prompt của thẻ đó → chọn ảnh trong thư viện ảnh (điện thoại) hoặc hộp chọn file (máy tính). Trên máy tính còn có thể dán Ctrl+V hoặc kéo thả ảnh vào ô. Rồi bấm 📤 Gửi ảnh này. Ảnh được nén ngay trên máy bạn rồi tự đưa lên GitHub — không cần mở Issue, hệ thống gán đúng ảnh theo mã trên thẻ, không đoán sai.

Gửi nhiều ảnh một lúc thì dùng nút 📤 Gửi ảnh cho CẢ NHÓM ở đầu mỗi nhóm — dán ảnh đúng thứ tự như danh sách mã. Không cần đổi tên ảnh, không cần gõ gì thêm.

🔑 Kết nối GitHub (làm 1 lần) — cần để trang tự đưa ảnh lên thay bạn. Dán token vào đây; token chỉ lưu trong trình duyệt này (localStorage), không gửi đi đâu ngoài GitHub.

🔗 Tạo token (quyền Contents: Read and write)
